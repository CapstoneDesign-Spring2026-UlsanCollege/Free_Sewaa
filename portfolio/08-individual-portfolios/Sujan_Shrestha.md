## 7. Challenges and Solutions

**Challenge 1 — Inconsistent UI Across Pages**
Early in development, different pages had different styling, layout patterns, and navigation approaches, making the platform feel disjointed.
- **Solution:** Worked with the team to define consistent navigation patterns, suggested reusable CSS classes, and aligned page layouts across the main user flows.

**Challenge 2 — Limited Documentation Organization**
Project documentation was scattered across the repository with no central navigation point, making it hard for team members to find key documents.
- **Solution:** Helped restructure `docs/README.md` as a central hub with categorized tables, contributed to sprint documentation, and ensured README files had consistent formatting.

**Challenge 3 — Messaging Interface Usability**
The messaging interface between donors and receivers was initially difficult to navigate on mobile devices.
- **Solution:** Redesigned the messaging layout with clearer conversation threading, improved the input area, and tested the interface on multiple screen sizes.
