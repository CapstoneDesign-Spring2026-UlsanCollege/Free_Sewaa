# Final MVP Demo Guide

## Demo Flow

The following flow demonstrates all core MVP features:

1. **Landing Page** — Project overview and navigation
2. **Sign Up** — Create a new user account
3. **Sign In** — Log in with credentials
4. **Browse Items** — View available donation items
5. **Post a Donation** — Create a new item listing
6. **Request an Item** — Submit a request for an item
7. **Messaging** — Communicate with other users
8. **User Dashboard** — View activity and manage listings
9. **Admin Panel** — Moderate content and manage users

## Known Demo Notes

- **Cold start:** First load after inactivity takes ~30 seconds
- **Images:** Uploaded images may appear large on some screens
- **"Just now" timestamp:** Item creation times may show "Just now" permanently
- **Session:** User session may be lost on page refresh (requires re-login)
- **Password recovery:** Not available (known limitation)
