# User Research

The repository preserves requirements-oriented user stories, flows, and a glossary. Formal interview transcripts or survey datasets were not found, so this section does not claim primary research that cannot be shown.

## User Stories

- [User Stories](../../../docs/PROJECT/USER_STORIES.md) — 12 user stories covering all features
  - Homepage, Email Auth, Browse Items, Item Detail, Post Item
  - Request Item, Messaging, Admin Dashboard, User Profile
  - Notifications, Saved Items
- [User Flow](../../../docs/USER_FLOW.md) — UML diagrams for all user journeys
- [Glossary](../../../docs/PROJECT/GLOSSARY.md) — Domain terms, technical terms, feature terms

## Design Use

These artifacts connect user goals to the post, browse, request, message, and administration flows. They should be evaluated as requirements evidence, not as proof that every story was completed.
