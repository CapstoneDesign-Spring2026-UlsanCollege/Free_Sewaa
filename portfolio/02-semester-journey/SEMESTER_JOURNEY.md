## Major Turning Points

1. **From idea to vertical slice:** The team narrowed a broad sharing-platform
   idea into the core Post -> Browse -> Request journey, giving the project a
   demonstrable user flow instead of a collection of disconnected pages.
2. **From frontend prototype to connected MVP:** Node.js API work, MongoDB
   integration, authentication paths, and frontend-to-backend connections moved
   Free Sewaa toward a full-stack application. Later React/Vite work remained
   partial, so the working static path was preserved for demo reliability.
3. **From feature claims to evidence-based closure:** Testing, bug reports,
   scope decisions, portfolio auditing, and final presentation preparation
   separated verified capabilities from open risks and future work. Week 16
   closes the project as an academic MVP, not a production-hardened service.

## Final Status

Week 16 is the final Spring 2026 capstone record. The submitted MVP demonstrates
the donation-sharing flow and preserves its technical, QA, ownership, and
presentation evidence. Security hardening, broader testing, frontend
consolidation, password recovery, email delivery, and production operations
remain post-capstone work.
