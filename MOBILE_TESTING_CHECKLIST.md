# Mobile Testing Checklist — Free Sewaa

Test on a 390x844 viewport (iPhone 14) using Chrome DevTools.

## Layout
- [ ] Landing page fits without horizontal scroll
- [ ] Navigation is accessible (no overlapping elements)
- [ ] Buttons and links are tappable (min 44x44px)
- [ ] Text is readable without zooming

## Forms
- [ ] Signup form fields stack vertically
- [ ] Login form usable on small screen
- [ ] Donate form inputs fill the width
- [ ] Submit buttons are reachable without scrolling far

## Browse
- [ ] Item cards stack in single column
- [ ] Category filter dropdown works
- [ ] Item detail page readable

## Admin
- [ ] Admin dashboard fits mobile width
- [ ] Tables scroll horizontally
- [ ] Action buttons (block, remove) are tappable

## General
- [ ] Touch targets are not too close together
- [ ] Back button works
- [ ] No content hidden off-screen
- [ ] Font size minimum 16px on inputs
