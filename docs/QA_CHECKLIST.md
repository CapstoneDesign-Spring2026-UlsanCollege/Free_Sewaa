# QA Checklist

## Pre-Release Checklist

### Authentication
- [ ] New user can sign up
- [ ] Returning user can log in
- [ ] Wrong password shows error
- [ ] Admin can log in
- [ ] Logout works

### Dashboard
- [ ] Dashboard loads after login
- [ ] Browse items page opens
- [ ] Messages page opens
- [ ] Profile page opens
- [ ] Notifications page opens

### Donation Items
- [ ] User can post a new item
- [ ] Item appears in browse page
- [ ] User can edit their item
- [ ] User can delete their item

### Requests
- [ ] User can request an item
- [ ] Donor sees incoming request
- [ ] Donor can accept/decline

### Messaging
- [ ] User can start a conversation
- [ ] Messages are sent and received
- [ ] Conversation history is visible

### Admin
- [ ] Admin dashboard loads
- [ ] Admin can view users
- [ ] Admin can block/unblock users
- [ ] Admin can remove/restore listings

### Mobile
- [ ] Navigation works on mobile width
- [ ] Forms fit screen
- [ ] Buttons are tappable
- [ ] No horizontal scroll

### Security
- [ ] Dashboard not accessible without login
- [ ] Admin not accessible by regular user
- [ ] Input validation works on forms

### Deployment
- [ ] Live site loads
- [ ] Signup works on live site
- [ ] Login works on live site
- [ ] Admin login works on live site

## Bug Priority Levels

| Priority | Meaning | Action |
|----------|---------|--------|
| P0 | Critical blocker | Fix immediately |
| P1 | Major issue | Fix before release |
| P2 | Medium issue | Fix when possible |
| P3 | Minor issue | Track for later |
