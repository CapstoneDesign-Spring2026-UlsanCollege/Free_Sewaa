# Week 11 Demo Script

**Total time:** About 5 minutes  
**Demo driver:** Mohan Khadka

---

## 1. Signup (30 seconds)

Open the live site and create a new account.

1. Go to https://free-sewaa-qh05.onrender.com
2. Click Sign Up in the top nav
3. Fill in:
   - First name, last name
   - Email (use a real email like @gmail.com)
   - Password (8+ chars, mix of upper, lower, numbers)
4. Click submit
5. You should land on the browse page logged in

---

## 2. Login (20 seconds)

If already signed up, just log in.

1. Click Sign In
2. Enter email and password
3. Click submit
4. Should go straight to browse page

---

## 3. Browse Items (30 seconds)

Show items that people donated.

1. Scroll through the grid of items
2. Use the search bar to find something
3. Try the category filter dropdown
4. Click on an item card to see details

---

## 4. Donate an Item (45 seconds)

Post something new for donation.

1. Click Donate in the top nav
2. Fill in the form:
   - Title (what is it?)
   - Description (condition, pickup info)
   - Category (Clothing, Books, Electronics, etc.)
   - Image URL (optional, uses default if blank)
3. Click submit
4. The new item should show up in browse

---

## 5. Request an Item (30 seconds)

Ask for an item and contact the donor.

1. Open an item in browse
2. Click Request or Contact Donor
3. Donor info should be visible
4. Send a message to the donor

---

## 6. Messaging (30 seconds)

Check your messages.

1. Click Messages in the nav
2. See conversation threads
3. Open a thread and read messages
4. Type a reply and send it

---

## 7. Admin Login (30 seconds)

Show the admin panel.

1. Go to https://free-sewaa-qh05.onrender.com/admin_login.html
2. Sign in with:
   - Email: admin@freesewaa.local
   - Password: admin12345
3. Show the overview dashboard
4. Point out users, items, and messages management
