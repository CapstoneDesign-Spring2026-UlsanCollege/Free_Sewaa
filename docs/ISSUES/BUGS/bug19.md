## Title
Bug: Empty Pages Lack Proper Feedback Messages

## Severity
P2 – User Experience Improvement

## Description
Some pages display blank sections when no data is available instead of showing meaningful empty-state messages.

## Steps to Reproduce
1. Open sections with no available data
2. Navigate to empty donation or notification pages
3. Observe displayed content

## Expected Behavior
Users should see informative empty-state messages and guidance when no content is available.

## Actual Behavior
- Blank screens appear
- Users receive no guidance
- Pages feel unfinished and confusing

## Suggested Fixes
- Add empty-state UI components
- Provide helpful placeholder messages
- Add navigation suggestions or actions
- Improve user guidance design
