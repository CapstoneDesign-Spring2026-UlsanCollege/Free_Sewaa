## Title
Bug: AI Bot Responses Lack Contextual Accuracy

## Severity
P2 – User Experience Improvement

## Description
The AI chatbot occasionally provides generic or unrelated responses that do not fully match user queries.

## Steps to Reproduce
1. Open AI chatbot section
2. Ask contextual questions about donations or services
3. Observe chatbot responses

## Expected Behavior
AI bot should provide context-aware and relevant responses to user queries.

## Actual Behavior
- Responses are overly generic
- Bot fails to understand some user intent
- Fallback responses appear too frequently

## Suggested Fixes
- Improve prompt engineering
- Add contextual memory handling
- Enhance fallback response logic
- Improve query intent detection

bug P2 AI chatbot enhancement
