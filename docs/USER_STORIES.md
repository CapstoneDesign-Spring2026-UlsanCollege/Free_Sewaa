# User Stories

## Authentication

- As a **new user**, I want to create an account so that I can start donating or requesting items.
- As a **returning user**, I want to log in so that I can access my dashboard and messages.
- As an **admin**, I want to log in through a separate admin page so that I can manage the platform.

## Browsing Items

- As a **user**, I want to browse all available donation items so that I can find something I need.
- As a **user**, I want to filter items by category so that I can narrow down what I am looking for.

## Posting Donations

- As a **user**, I want to post an item with a photo and description so that others can see what I am offering.
- As a **user**, I want to edit or remove my post so that I can keep my listings up to date.

## Requesting Items

- As a **user**, I want to request an item so that the donor knows I am interested.
- As a **donor**, I want to see who requested my item so that I can choose to give it to them.

## Messaging

- As a **user**, I want to send a message to a donor so that I can arrange pickup.
- As a **user**, I want to see my conversations so that I can keep track of my chats.

## Admin Management

- As an **admin**, I want to view platform statistics so that I can monitor activity.
- As an **admin**, I want to block problem users so that the platform stays safe.
- As an **admin**, I want to remove inappropriate listings so that content stays appropriate.

## Profile

- As a **user**, I want to view my profile so that I can see my information and activity.
- As a **user**, I want to save items so that I can find them later.
