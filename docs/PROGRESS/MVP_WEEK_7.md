## 🎯 Objectives
- Complete frontend-backend integration
- Fix critical bugs discovered during testing

---

## 🔹 Core Features

### 1. End-to-End Testing
- Test user signup → MongoDB storage → User can login
- Test item donation → Saved in MongoDB → Visible in browse
- Test item request → Status saved → Visible in user requests
- Test profile updates → Reflected in database

### 2. Input Validation
- Email format validation on signup/login
- Phone number format validation
- Form field length checks
- Category and condition validation
- Image file type and size validation

### 3. Error Handling
- Display user-friendly error messages
- Handle network errors gracefully
- Provide clear feedback on API failures
- Toast notifications for success/error states

### 4. Midterm Documentation
- Create MVP checklist with status updates
- Document completed features
- List pending items
- Prepare team contribution receipts
- Create evidence folder with screenshots

### 5. Demo Preparation
- Record demo video showing all major features
- Create demo script with step-by-step instructions
- Test on fresh browser (incognito mode)
- Prepare talking points for presentation
