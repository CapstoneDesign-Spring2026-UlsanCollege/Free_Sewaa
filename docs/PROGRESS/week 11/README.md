# Week 11 — MVP Verification

**Theme:** Capstone Design MVP Verification

**Goal:** Validate the MVP core flow effectively.

---

## Core MVP Flow

1. User opens Free Sewaa
2. User signs up or logs in
3. User browses donation items
4. User posts a donation item
5. Another user requests or contacts donor
6. Admin can review platform
7. Team shows proof with screenshots, PRs, test results, docs update, review comment, and CI run

---

## Track Explanation

| Track | Meaning |
|-------|---------|
| **A — MVP Recovery** | App is unreliable or unexplained |
| **B — MVP Stabilization** | App mostly works, but bugs, docs, or tests are weak |
| **C — MVP Plus** | App works, team understands it, ready for polish |

**Our target:** Track B now, moving toward Track C.
