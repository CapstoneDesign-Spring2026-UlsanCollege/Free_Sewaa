## 1. Landing Page
**What:** Show the hero section, featured items, and navigation.

**Actions:**
- Scroll through landing page
- Note the clean UI and responsive layout

---

## 2. User Signup
**What:** Register a new user account.

**Actions:**
- Click "Sign Up" in navigation
- Fill out: firstName, lastName, email, password
- Submit and verify redirect to browse page

---

## 3. Browse Items
**What:** View available donation items.

**Actions:**
- Browse the grid of available items
- Use search bar to find items
- Use category filter to narrow results
- Click an item card to see details

---

## 4. Donate an Item
**What:** Post a new item for donation.

**Actions:**
- Click "Donate" in navigation
- Fill out item details (title, description, category, image)
- Submit and verify item appears in browse

---

## 5. Request / Contact Donor
**What:** Request an item and message the donor.

**Actions:**
- Click "Request" on an item
- View donor contact information
- Send a message via the messaging system

---

## 6. Messaging
**What:** Send and receive messages.

**Actions:**
- Open Messages page
- View conversation threads
- Send a new message reply

---

## 7. Admin Dashboard
**What:** Admin panel for managing the platform.

**Actions:**
- Navigate to /admin_login.html
- Sign in with admin@freesewaa.local / admin12345
- View users, items, and messages management
