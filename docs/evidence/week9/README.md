## How to Add Evidence

### 1. Take Screenshots
- **Mac**: `⌘+Shift+4` (select area)
- **Windows**: `Win+Shift+S` (snip tool)
- **Browser**: Right-click → "Take screenshot"

### 2. Save to This Folder
```
docs/evidence/week9/
├── week10-sprint-packet.png
├── bug-issues.png
├── board-snapshot.png
├── ai-use-note.png
├── contribution-receipts.png
├── code-ownership.png
├── demo-screenshot.png
└── ci-pass.png
```

### 3. Commit and Push
```bash
git add docs/evidence/week9/
git commit -m "add week 10 evidence"
git push origin main
```
