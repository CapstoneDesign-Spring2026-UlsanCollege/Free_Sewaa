## How to Add Screenshots

1. Take screenshot (Mac: `Cmd+Shift+4`, Windows: `Win+Shift+S`)
2. Save file in this folder with a clear name, e.g.:
   - `week11-landing.png`
   - `week11-browse.png`
   - `week11-donate.png`
   - `week11-messages.png`
   - `week11-admin.png`
   - `week11-test-results.png`
   - `week11-ci-run.png`
3. Commit and push:
   ```bash
   git add docs/evidence/week11/
   git commit -m "add week 11 evidence screenshots"
   git push origin main
   ```
