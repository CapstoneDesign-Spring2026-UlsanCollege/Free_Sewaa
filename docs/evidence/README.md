## How to Add Evidence#

### 1. Take Screenshots
- **Mac**: `⌘+Shift+4` (select area)
- **Windows**: `Win+Shift+S` (snip tool)
- **Browser**: Right-click → "Take screenshot"

### 2. Save Evidence
```
docs/evidence/
├── week1-homepage.png
├── week2-login.png
├── week3-browse.png
├── week4-filter.png
├── week5-donate.png
├── week6-api.png
├── week7-presentation.pdf
├── week9-testing.png
└── week10-bugs.png
```

### 3. Commit and Push
```bash
git add docs/evidence/
git commit -m "add week X evidence"
git push origin main
```
