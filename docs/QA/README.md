# Quality Assurance Documents

This directory groups the focused review checklists used during Free Sewaa's capstone testing and final review.

> These checklists record review coverage and expected checks. They are not, by themselves, proof that every item was executed; see the linked QA reports and final portfolio for executed evidence.

| Checklist | Focus |
|---|---|
| [Accessibility](ACCESSIBILITY_CHECKLIST.md) | Keyboard, contrast, labels, and assistive technology |
| [Admin Review](ADMIN_REVIEW_CHECKLIST.md) | Administrative access and moderation workflows |
| [Browser Testing](BROWSER_TESTING_CHECKLIST.md) | Cross-browser behavior |
| [Form Validation](FORM_VALIDATION_CHECKLIST.md) | Client and server validation |
| [Manual Testing](MANUAL_TESTING_CHECKLIST.md) | End-to-end feature checks |
| [Mobile Testing](MOBILE_TESTING_CHECKLIST.md) | Responsive layouts and touch interaction |
| [Security](SECURITY_CHECKLIST.md) | Authentication, authorization, input, and deployment review |
