# Glossary

| Term | Definition |
|------|------------|
| Admin | A user with platform management privileges. Can manage users, listings, and view reports. |
| API | Application Programming Interface. The backend endpoints that the frontend calls to read and write data. |
| Browse | The page where users can view all available donation items. |
| Donation Item | An item that a user has posted for free donation (e.g. clothing, books, furniture). |
| Donor | A user who posts items for donation. |
| Dashboard | The main page a user sees after logging in. Contains navigation to all features. |
| Deployment | The process of making the app available on the internet (currently hosted on Render). |
| JWT | JSON Web Token. A token-based authentication method (planned for future use). |
| Listing | Another term for a donation item posted on the platform. |
| MongoDB | The NoSQL database used to store all application data. |
| Node.js | The JavaScript runtime used for the backend server. |
| Receiver | A user who requests and receives donated items. |
| Render | The cloud platform used to host the live application. |
| Request | An action where a user expresses interest in a donation item. |
| Superadmin | The highest admin role with full platform access. |
| User | Any person who creates an account on Free Sewaa. |
