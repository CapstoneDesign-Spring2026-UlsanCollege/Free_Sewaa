# Team roles (rotate weekly)

### PM (Project Manager)

- Create the **Weekly Sprint Packet** GitHub Issue (use the course template)  
- Coordinate tasks and blockers  
- Ensure work is visible on the **Project board** and in the repo  
- Submit the packet **before the course deadline** (typically Friday, per syllabus)

### Scribe

- Record decisions and sprint notes  
- Keep [`docs/`](.) and [`docs/question.md`](question.md) current  
- Track risks and link evidence

### QA Lead

- Verify features before demos  
- Confirm repro steps for bugs (see [`ISSUES/BUGS/`](ISSUES/BUGS/))  
- Support **definition of done** for the sprint

### Demo Driver

- Demo script (3 bullets) + **backup plan** (video/screenshots)  
- Run the live demo in class or record it for the Sprint Packet

# Communication

| Tool | Purpose |
| --- | --- |
| KakaoTalk | Quick coordination |
| Discord | Longer discussion, files |
| GitHub Issues & PRs | Source of truth for work and reviews |

### Communication expectations

- Reply within **24 hours** when possible  
- Tell the team early if you cannot attend  
- Ask for help instead of staying silent  

### Meetings

- **Wednesday after class** (typical) for stand-up, blockers, and GitHub hygiene  
- End with **clear owners** and **visible** Issues/PRs  

---

# GitHub workflow rules

```text
Issue → Branch → Pull Request → Merge → Evidence
```

- No substantial work **without an Issue** (or explicit task linked from the board)  
- Use **feature branches** and **PRs** to merge to `main`  
- **Review** meaningful changes when the team agrees  

---

# Evidence rule

This course is **evidence-based**.

> **If it isn’t linked, it didn’t happen.**

Each student posts **2–3 receipts per week** as comments on the **Weekly Sprint Packet** issue (PRs, commits, closed issues, reviews, CI, documentation commits, screenshots **with** links).

See [`POLICY - Evidence & Receipt.md`](POLICY%20-%20Evidence%20&%20Receipt.md).

---

# Work expectations

- Contribute **every week** with verifiable links  
- Post receipts on the Sprint Packet issue  
- Surface blockers early  
- Respect teammates’ time  

---

# Missed work

1. Inform the team  
2. Complete work when possible  
3. **Late policy:** Per syllabus — missed deadlines may score **zero** even if completed later  

---

# Conflict resolution

1. Discuss in the team  
2. Adjust ownership if needed  
3. **Document** in GitHub (Issue or comment)  
4. Escalate to the **instructor** if unresolved  

---

# Freeloading policy

Repeated **missing receipts**, **no commits**, or **no communication** may trigger reassignment, individual grade impact, or instructor intervention — per course rules.

---

# Team decision rules

- **Routine decisions:** majority  
- **Major scope or tech changes:** **full team** agreement
