# Glossary

Terms used in the Free Sewaa project.

---

## Domain Terms

| Term | Definition |
|------|-----------|
| **Sewaa** | Korean: help/assistance. The project name means "free help." | 
| **Donor** | A user who posts items to give away for free |
| **Requester** | A user who requests an item from a donor |
| **Donation** | An item listed for free on the platform |
| **Request** | An action where a requester asks for a donation item |
| **Pickup** | The physical exchange of a donated item |
| **Premium UI** | High-quality user interface inspired by Airbnb/Karrot design |

## Technical Terms

| Term | Definition |
|------|-----------|
| **MVP** | Minimum Viable Product — the smallest working version of the app |
| **Core Flow** | The main user journey from opening the app to completing a donation |
| **Sprint** | A 1-week development cycle in this course |
| **Sprint Packet** | Weekly submission documenting progress, evidence, and plans |
| **Track** | The team's progress level: A (Recovery), B (Stabilization), C (Plus) |
| **Evidence** | Proof that a sprint requirement was met (screenshots, PRs, test results) |
| **DoD** | Definition of Done — criteria for completing a task |
| **P0/P1/P2/P3** | Bug priority levels (Critical → Cosmetic) |
| **PM** | Project Manager — team coordination role |
| **QA** | Quality Assurance — testing and bug verification |
| **Scribe** | Documentation and repo management role |
| **PR** | Pull Request — code change submitted for review |
| **CI** | Continuous Integration — automated testing on each push |

## Feature Terms

| Term | Definition |
|------|-----------|
| **Browse** | Page where users view all available donation items |
| **Donate** | Page/action where users post items to give away |
| **Messages** | Real-time chat between donors and requesters |
| **Dashboard** | User's personal page showing their items and requests |
| **Admin Panel** | Management page for platform administrators |
| **Dark Mode** | Alternative color scheme with dark background |
| **Saved Items** | Bookmarked donations a user wants to remember |
| **Quick Replies** | Pre-set message templates for common chat responses |

## Document Types

| Term | Definition |
|------|-----------|
| **README** | Main project overview file |
| **ROADMAP** | Project timeline and future plans |
| **CHANGELOG** | Version history and release notes |
| **Bug Report** | Documented issue with steps to reproduce |
| **Sprint Packet** | Weekly progress submission |
| **Evidence Links** | List of proof items for sprint requirements |
| **Ownership Map** | Team member roles and file assignments |
| **Demo Script** | Step-by-step presentation guide |
| **Risk Register** | Documented project risks and mitigations |
| **Lessons Learned** | Retrospective on what went well and what to improve |
