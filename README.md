### Features

- User authentication (signup/login)
- Browse donation items with category filters
- Post items for donation with images
- Request items and message donors
- Admin dashboard for management
- Responsive design (mobile + desktop)
- Unit testing with Jest

## Quick Start

```bash
git clone https://github.com/CapstoneDesign-Spring2026-UlsanCollege/Free_Sewaa.git
cd Free_Sewaa
npm install
npm start
```

Open http://localhost:3000

**Requirements:** Node.js 18+, MongoDB 6+ running locally.
