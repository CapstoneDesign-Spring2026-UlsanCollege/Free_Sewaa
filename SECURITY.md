# Security Policy

## ⚠️ Important Notice
Free Sewaa is a **student capstone demo project**. It is not intended for production use with real personal data.

**Please do not:**
- Create accounts with your real personal information
- Store sensitive data through this platform
- Use real passwords you use elsewhere

## Supported Versions
This project is under active development as part of Spring 2026 Capstone Design at Ulsan College.

| Version | Supported |
|---------|-----------|
| Current (main branch) | ✅ |
| Older branches | ❌ |

## Reporting a Vulnerability
If you discover a security issue, please **do not open a public GitHub issue**.

Instead, contact the team via the repository Discussions tab or reach out to the project manager directly.

We will respond within 3 business days and credit responsible disclosures.

## Known Limitations
- Passwords are stored in plaintext (demo only — not production-grade; bcryptjs available for future use)
- Admin credentials are demo-only and should never be used in real deployments
- No HTTPS enforced on local development builds
