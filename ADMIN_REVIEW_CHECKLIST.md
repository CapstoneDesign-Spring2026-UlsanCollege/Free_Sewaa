# Admin Review Checklist — Free Sewaa

## Admin Login
- [ ] Admin login page loads
- [ ] Admin credentials work: admin@freesewaa.local / admin12345
- [ ] User login cannot access admin panel

## Dashboard Overview
- [ ] Stats display: total users, listings, requests, conversations
- [ ] Recent users list shows latest signups
- [ ] Recent listings show latest donations

## User Management
- [ ] User list loads all registered users
- [ ] Can block a user
- [ ] Blocked user cannot log in
- [ ] Can unblock a user
- [ ] Can demote admin to regular user
- [ ] Can make a user superadmin

## Listing Management
- [ ] Listing list loads all donations
- [ ] Can remove inappropriate listings
- [ ] Removed listing hidden from Browse

## Security
- [ ] Admin endpoints require superadmin role
- [ ] Direct URL access to admin pages redirects if not logged in
- [ ] Admin actions are logged (if audit endpoint exists)

## Mobile
- [ ] Admin panel usable on mobile
- [ ] Tables scroll horizontally on small screens
