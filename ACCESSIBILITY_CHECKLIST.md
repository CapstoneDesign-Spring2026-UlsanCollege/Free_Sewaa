# Accessibility Checklist — Free Sewaa

## Screen Readers & Keyboard
- [ ] All images have alt text
- [ ] Form inputs have labels
- [ ] Page structure uses semantic HTML (header, nav, main, footer)
- [ ] Tab order follows visual layout
- [ ] All interactive elements are focusable
- [ ] No keyboard traps

## Color & Contrast
- [ ] Text has sufficient contrast against background
- [ ] Links are distinguishable from body text (underline or bold)
- [ ] Error messages use color + icon, not color alone
- [ ] Focus indicators visible on all interactive elements
- [ ] Buttons have `:focus-visible` outline (2px bronze)
- [ ] Nav links have `:focus-visible` outline (2px bronze)
- [ ] Icon links have `:focus-visible` outline (2px bronze)

## Forms
- [ ] Required fields marked (asterisk or label)
- [ ] Error messages associated with their input
- [ ] Helper text provided for password rules, email format
- [ ] Submit buttons have descriptive text

## Navigation
- [ ] Skip navigation link available
- [ ] Current page indicated in navigation
- [ ] Back/forward browser buttons work
- [ ] Page titles are descriptive

## Text
- [ ] Font size is at least 16px on inputs
- [ ] Line height is at least 1.5
- [ ] Text can be resized without breaking layout
- [ ] No text in images

## Testing
- [ ] Tested with browser zoom at 200%
- [ ] Tested with keyboard-only navigation
- [ ] Tested with Chrome Lighthouse Accessibility audit
