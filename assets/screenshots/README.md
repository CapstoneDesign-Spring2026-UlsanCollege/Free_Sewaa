## Capture Guide

### Desktop Screenshots
1. Open the live site at https://free-sewaa-qh05.onrender.com
2. Set browser to 1920x1080 viewport (use DevTools if needed)
3. Use your OS screenshot tool:
   - **macOS:** Cmd+Shift+4, select area
   - **Windows:** Snipping Tool or Win+Shift+S
   - **Browser:** Right-click → "Take Screenshot" (Chrome DevTools)
4. Save as PNG into this folder

### Mobile Screenshots
1. Open Chrome DevTools (F12)
2. Toggle Device Toolbar (Ctrl+Shift+M)
3. Select iPhone 14 or similar (390x844)
4. Capture each screen

### Auth Flow Diagram
1. Open `html/auth-flow.html` in a browser
2. Capture the full flowchart (may need to scroll)
3. Or use a browser extension for full-page capture
